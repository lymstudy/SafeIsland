## 2. 一键运行

将 `submission/` 解压后：

```bash
cd submission/scripts

# 功能仿真（34 case + 行覆盖率）  ~2 min
bash run_functional.sh

# 注错仿真（baseline + batch + campaign）  ~30 min
bash run_fault.sh

# 全套
bash run_all.sh
```

## 5. 注错结果分类

| 分类 | 含义 |
|------|------|
| **corrected** | TMR 纠错，功能输出正确 |
| **detected** | 10 cycle 内 fault_detect / safety_island_fault_detect 上报 |
| **latent** | shadow/parity/TMR mismatch 上报，功能输出保持正确 |
| **safe** | 故障未激活或未传播 |
| **undetected** | 输出错误且未上报（功能逃逸） |

保护率 = (corrected + detected + latent + safe) / 总故障数
