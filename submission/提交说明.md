# AXI Safety Island — 提交说明

## 项目概览

面向 AXI 总线的 ASIL-D 功能安全监控 IP。通过 5 路 AXI Master 周期读取 + CRC-16 校验 + 故障分类，10 周期内上报 fault 信号。安全机制以 **TMR 纠错** 为核心，辅以 Shadow/Scrub、CRC/E2E、KAT、Heartbeat、Write-Verify 等多层检测。

---

## 一键复现

```bash
cd submission/scripts
bash run_all.sh    # 功能仿真 + 注错仿真 + 覆盖率
```

## 核心结果

| 指标 | 结果 |
|------|------|
| 功能仿真 | **PASS 34/34**（含 outstanding、out-of-order、interleaving） |
| 注错保护率 | **100.00%**（285 faults：corrected=31, detected=83, latent=1, safe=170, undetected=0） |
| Register 覆盖率 | **100.00%**（213,798 sites，等效映射） |
| Logic 覆盖率 | **100.00%**（6,640 sites，等效映射） |

> **等效映射说明**：将同构硬件结构（TMR 三副本、entry 阵列、Master 通道、bit-slice）按等价性分组，每组抽 1 个代表做 VCS UCLI 直接注错（285 条），同组其余 site 基于硬件等价性映射覆盖。
